# CLAUDE.md

Инструкции для Claude Code при работе с этим репозиторием.

## О проекте

Одностраничный лендинг падел-клуба **TOP PADEL ALICANTE**, перенесённый с Figma-макета
(файл `4bKUFsKyfjHpEqKE4EB8RG`, нода `1:2` — это плоский скриншот, без реальных слоёв/токенов).
Подробности стека, структуры и адаптива — см. `README.md`, он актуален и не нужно его дублировать здесь.

## Конвенции, которых нужно придерживаться

- **Весь текст на сайте — на русском.** Оригинальный макет был смешан рус/укр — при переносе контента нормализуем в русский.
- **Без футера** — это осознанное решение, не забытая секция.
- Стилизация — **CSS Modules** (`Component.module.css` рядом с компонентом) + общие токены в `app/globals.css`. Не вводить CSS-in-JS или Tailwind.
- Контент секций (тексты, ссылки, данные карточек/статей) держать в `lib/data.ts`, а не хардкодить в компонентах.
- Ссылки (`href`) сейчас везде плейсхолдер `#` — это ожидаемо, не «чинить» без реальных URL.
- Изображения в `public/images/*.svg` — временные плейсхолдеры для верстки, не финальные ассеты.
- Анимации на скролл — через существующий `components/Reveal.tsx` (IntersectionObserver, уважает `prefers-reduced-motion`); не добавлять сторонние анимационные библиотеки.
- Запись контента — только через `lib/content/core.ts`. Проверку доступа он не делает
  намеренно: её добавляет каждый вход сам (веб-админка — cookie-сессией, Telegram-бот —
  сверкой с `TELEGRAM_ADMIN_IDS`). Не дублировать логику правок во втором месте.
- Разделы и поля Telegram-бота описываются таблицей в `lib/telegram/sections.ts`;
  экраны собираются из неё — не писать отдельное меню под каждый раздел.
- Шрифт — self-hosted вариативный **Onest** (`public/fonts/*.woff2`); не подключать шрифты через Google Fonts CDN.

## Проверка перед отчётом о готовности

- `npm run build` должен проходить без ошибок TypeScript.
- Для визуальных изменений — поднять `npm run dev` и проверить в браузере на нескольких брейкпоинтах (см. список в README), т.к. вёрстка fluid/адаптивная.
